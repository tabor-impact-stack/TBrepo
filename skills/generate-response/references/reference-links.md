# Pre-approved reference links

These are verified and can be used in customer drafts directly, without a site search.

## Legal and platform agreements

Use these when a customer, brand, or media partner asks for platform terms, service agreements, or legal policies.

- impact.com Master Program Agreement (MPA): https://impact.com/legal/impact.com_Master_Program_Agreement.pdf
  Framework for program terms between brands (advertisers) and partners.
- Media Partner Service Agreement (in-app view): https://app.impact.com/content/displaympserviceagreement.ihtml
  On-platform terms for media partners.
- Partner Services Agreement (PDF): https://impact.com/legal/Partner-services-agmt-0525.pdf
  Downloadable agreement covering partner participation and compliance.

When you write one of these into a draft, use markdown anchor text, for example `[Partner Services Agreement](https://impact.com/legal/Partner-services-agmt-0525.pdf)`.
