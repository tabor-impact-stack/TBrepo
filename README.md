# Customer Solutions Claude skills

Snapshot of the Customer Solutions skills for impact.com, taken 2026-11-19.

Internal use only. These skills reference internal Slack channels, Jira queues, and Operator details. Do not share outside impact.com.

## What is here

The skills folder holds one folder per skill, each with a SKILL.md and, where present, a references folder. Some Confluence-based items are still open decisions and are flagged inside the skill files.

## Using them

- Claude Code: clone this repository and open the folder. Claude Code loads the skills from the skills folder.
- Claude app: the skills must be added to your own account. Copy each SKILL.md into a skill of the same name.

## Updating

These are copies. When a skill changes in the source account, the matching folder here needs to be updated and committed as well.
